# Security policy

## Reporting a vulnerability

Please do not publish exploitable details in a public issue. Contact the repository maintainer privately through the GitHub profile or use GitHub's private vulnerability reporting feature if enabled. Include affected versions, impact, reproduction steps, and a suggested mitigation when possible.

## Scope

This project is provided as developer tooling, not as a substitute for a dedicated security review. Findings can be false positives or false negatives. Do not send secrets or confidential datasets when reporting a problem.
